# 김영현 포트폴리오

반응형으로 제작한 정적 포트폴리오 웹사이트입니다.

## 로컬에서 보기

`index.html`을 열거나 VS Code의 Live Server로 실행하세요. `index.html`은 실제 메인 화면인 `main.html`로 연결됩니다.

## 주요 파일

- `main.html`: 메인 화면 구조
- `styles.css`: 메인 화면 스타일과 반응형 레이아웃
- `script.js`: 프로젝트 카드, 탭 필터, 인트로 동작
- `detail.css`: 프로젝트 상세페이지 공통 스타일
- `picl.html`, `compose.html`, `groundseesaw.html`, `runon.html`, `dandi.html`, `goodal-ai.html`: 프로젝트 상세페이지
- `images/projects/`: 카드 썸네일과 상세 작업 이미지

## GitHub Pages로 공개하기

1. 이 폴더를 GitHub 저장소에 올립니다.
2. 저장소의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`로 선택합니다.
3. 브랜치는 `main`, 폴더는 `/ (root)`로 지정하고 저장합니다.
4. Pages 설정 화면에 표시되는 주소에서 사이트를 확인합니다.
